## 已检查

- 用实际 Chromium 在禁用 JavaScript 的环境中渲染全部三张界面，截图由该 HTML 生成。
- HTML 内没有脚本；已阻止外部网络请求，渲染过程中外部请求为 0，素材图片全部成功显示。
- 三张桌面画布宽度均为 1440 像素，没有画布内的横向溢出；页面允许纵向滚动。
- 390 像素视口的网页本身没有横向溢出，画布可以在容器内横向查看。正式桌面界面的窄窗口抽屉是后续实现要求，静态效果稿未实现该交互。
