序幕 · 创作者工作台 — 界面效果演示

1. 解压后，使用 Windows Edge 或 Chrome 打开“index.html”或“序幕-交互演示.html”。
2. 左侧可切换工作概览、账号管理、素材库、发布任务和消息中心。
3. 可以添加账号档案、导入 MP4/MOV 文件信息、创建任务、运行演示和保存消息草稿。
4. 修改保存在当前浏览器内；需要备份时，在“工作区设置”中导出 JSON。

说明：
这是界面演示，不是 Windows 安装包。示例账号、图表和消息均为虚构。
没有接通真实扫码登录、抖音发布或消息同步，不会发布视频或发送消息。
导入只保存文件名和大小等信息，不会上传或持久保存原始视频。
移动文件、更换浏览器或清理网站数据可能导致本地记录不再可用。
Windows 实机运行尚未验证。预览不允许脚本运行时，页面会保留实际界面截图。
如果聊天里的内置预览此前出错，重新加载更新后的 Index。不要选择 development.html，该文件是开发源码入口。
