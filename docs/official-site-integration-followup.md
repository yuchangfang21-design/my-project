# 官方账号接入跟进

2026-10-18：用户已在 Windows 安装0.4.1，并反馈已完成官方扫码。截图显示应用仍为待确认。该反馈不能代替软件读取当前远端账号身份。

## 已定位的缺口

- `desktop/browser/douyin.ts` 的 `observeIdentity` 始终返回null，尚无真实身份解析器。
- 主进程仍绑定 `UnverifiedPublishAdapter`、`UnverifiedCommentsAdapter`，没有真实发布或评论读写能力。
- 本轮重测 `creator.douyin.com`、`open.douyin.com`、`www.douyin.com` 均被当前运行环境代理拒绝，返回CONNECT 403。保存网络草稿不代表当前环境已经允许访问。
- 这个云端会话没有连接用户Windows官方浏览器的通道。扫码不授予开发者远程操作权限。

公开实现 `dreammis/social-auto-upload` 的上传流程可作为研究参考，但它的URL跳转判定、页面控件和发布结果处理不能替代本项目要求的稳定账号标识、作品回执及用户设备验证。本轮未复制它的实现，也未用它宣称接入成功。

## 本机只读检查

0.4.2增加账号卡片上的“生成接入检查”，无需用户查找地址栏。用户先打开该账号的官方浏览器，自己扫码；返回应用点击检查，预览报告后自行决定是否复制到开发对话。

报告仅含最多5个标签页的官方站点类别、脱敏路由、有限控件计数及每页最多20个已存在的接口资源路由。仅保留预先列明的公共路径单词，其他路径段替换为`[segment]`。不包含网址参数、片段、账号名称或标识、网页标题、页面正文、表单内容、截图、Cookie、密码、认证头或浏览器配置。

检查不刷新或跳转页面、不发起网络请求、不点击控件、不改写表单、不上传报告、不修改登录状态。外站标签页不检查内容；文档检查前及检查后都核对位置。无法读取或超时的标签页标记unavailable。检查结果不作为身份、发布或评论能力证明。

现有“检查状态”的提示改为明确告知软件身份识别尚未接入，避免让用户反复扫码。真实适配器继续保持未接通，不能通过手动修改数据库或测试开关冒充上线。
