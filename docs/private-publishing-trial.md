## 本轮范围

仅允许一个账号、一个任务，30字以内非空标题、1000字以内正文、不填标签、正文末尾不带空白；用户核对后执行一次。软件先检查同文案作品，拒绝覆盖既有草稿，再上传受管文件、填写文案、选择私密并回读。正式点击前同步确认控件仍在当前文档中且唯一，标题、正文、私密选项、按钮状态未变化。已提交或结果不明不会再次点击。

官方DOM的可访问角色及发布响应仍没有实机证据。因此选择器、管理页路径和只读响应识别规则均为**待验收候选**；不匹配时停止，不会降级为公开发布或猜测成功。候选响应仅观察此次点击后主框架发起的官方 POST fetch/XHR，路径 `/web/api/[vN/]media/aweme/create|publish/`，JSON响应须有不超过64KiB的有效Content-Length。只读取本次新作品ID，不调用候选API写入。若真实站点使用其他路径、分块响应或不同字段，会保留结果待核对。

只有本次响应里的唯一作品ID、同账号官方列表中唯一文案的可见“已发布”状态、精确匹配ID的官方作品链接全部一致，才记成功。作品链接只保留必要的modal_id，不保存跟踪参数。重启后缺少本次内存证据时，不靠文案或旧链接补造成功。

## Windows上只做一次测试

1. 安装本版，打开原账号的独立官方浏览器；回到软件点击“检查状态”，确认官网昵称正确。
2. 导入一段小视频，创建**一个**任务。使用从未发过的新标题，正文简短，不填标签。
3. 选择该任务，点击“核对并启动”。确认账号、视频和文案正确，并且可见范围显示“仅自己可见 · 单视频联调”。勾选核对后点击“确认发布1条”。
4. 保持软件与账号浏览器打开。成功后在官方作品列表核实私密范围；若出现失败或“结果待核对”，先检查官方列表，不重复发布。
5. 只反馈软件最终状态或错误提示即可，无需Cookie、接口全文或开发者工具。

评论读取/回复和私信仍未接通；此版本不包含自动刷视频、公开批量发布或定时发布。
