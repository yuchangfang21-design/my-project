| 部分 | 当前行为 |
| --- | --- |
| 任务准备 | 每个账号独立标题、说明、标签；修订冲突保留输入；素材编辑不覆盖已保存的任务 |

| 执行核心 | 全局串行、同一确认去重；提交前持久记录意图；不确定结果暂停整批且不自动重发 |

| 重启 | 仅恢复状态、不执行队列；提交标记前回到待执行，标记后结果待核对 |
| 数据迁移 | schema 1 → 2 前生成包含 WAL 的一致性备份；失败回滚，拒绝写入未来版本 |
| 桌面交互 | 宽屏列表与详情并排，960px 抽屉；核对弹层有键盘焦点约束；运行批次暂停入口跨页面保留 |
| 真实身份与发布 | 默认未验证；无产品配置开关，无虚构 DOM 选择器，不因历史登录状态启用 |
| Windows 安装 | 构建工作流与原生打包验收已扩充；成功产物及实机结果待确认 |
| 评论、私信、自动刷视频 | 本次未实现；消息工作台仍属于静态设计 |

## 工程裁定与代价（Rulings）

1. 沿用当前隔离云工作区与 `preview/xumu-demo` 分支：不新建 worktree；代价是只使用云工作区这一层隔离。
2. 技能辅助脚本及链接测试参考不可读取时，手工维护等价任务、测试与裁定记录，执行已读取的 TDD 规则；代价是没有辅助脚本自动化。
3. 任务 1 提前扩充桌面状态兼容类型以保持编译，演示持久化白名单保持独立；代价是新 UI 之前共享视图类型已经扩大。
4. 中断恢复在任务 2 随真实尝试事务及测试实现，不在任务 1 放空实现；代价是任务 1 单独只交付存储与迁移。
5. 每次尝试持久化确认快照及适配器版本，增加内部批次查询/完成逻辑，暂停时释放未开始的预留；代价是记录略大、事务路径更多，已覆盖测试。
6. 内部动作有独立超时预算；超时后先保存不确定结果，关闭对应 context 并等待原动作结束；代价是若损坏适配器在 context 关闭后永不结束，队列保持阻塞，不能冒险与其并发写入。当前生产适配器禁用。
7. 增加只读批次列表并在页面进入时恢复暂停入口；代价是额外 DTO 查询，已完成历史限最近 20 个批次。
8. 官方访问受阻时交付禁用适配器与原生验收步骤，不制作猜测的选择器；代价是真实身份与发布仍不可用。
9. 用真实 Linux 打包程序扩充旧库升级与修订重启验收，不为已经实现的行为制造人工 RED；代价是此包装层验收不替代 Windows 原生运行，核心行为的失败测试已在对应任务先行完成。
10. Windows 工作流使用 `npm ci --ignore-scripts` 后显式准备 Electron；代价是依赖新增安装脚本时需明确评估，当前依赖无变化且 Linux 实际加载验证通过。

独立审阅的发现、修复与延后的小问题将在最终复核后记录。
