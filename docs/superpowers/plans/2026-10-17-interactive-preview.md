# Windows 首版交互效果演示实施计划

用户已通过书面设计，并要求查看实际效果。本次先交付可以运行的浏览器界面演示，不声称已经实现 Electron 安装包、抖音登录或真实发布与消息接入。

1. 使用 React、TypeScript、Vite 实现中文桌面布局，包含概览、账号管理、素材库、发布任务、消息中心和设置。
2. 使用明确标记的示例账号、示例素材、模拟数据展示界面；用户添加的账号一律显示未连接。
3. 实现本地账号档案、视频信息导入与编辑、发布任务映射、带显式确认的演示执行、消息草稿与本地处理状态，持久化到浏览器本地存储。
4. 不收集账号密码和 Cookie，不模拟二维码，不把演示任务成功标记为真实发布成功；真实登录入口仅打开官方网页。
5. 用 Chromium 和 Playwright 验证主要用户流程、跨刷新持久化、演示结果标识及界面窄屏表现；运行 TypeScript 与生产构建。
6. 生成实际渲染截图和启动说明；分别报告本地演示与真实站点接入状态。

导入仅保存本地文件名等元信息；本演示不复制或上传原始视频。应用启动与 Windows 安装包仍按产品设计文档在后续阶段实现。
